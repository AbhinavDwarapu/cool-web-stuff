# My Super Cool Web Collection
Some web libraries and designs and other web stuff I've been collecting :)

Most of these have a NextJS, TailwindCSS and ShadCN bias since I use them the most. 

### ShadCN components

[ShadCN](https://ui.shadcn.com/) has a set of nicely designed components that gets copy-pasted directly into your codebase. Alongside this library, lots of other component systems follow a similar philosophy of "copy-paste into codebase".

| Library     | Description | Links          |
| :---        |    :----   |          :---: |
| 21st | Tons of great community built ShadCN components and blocks. Great place to get inspired.| [link](https://21st.dev/)  |
| MagicUI      | Lots of effects and nicely animated components.| [link](https://magicui.design/)  |
| OriginUI      | Similar to ShadCN primitives but with more options.| [link](https://originui.com/)  |
| BuouUI      | Lots of effects and nicely animated components.| [link](https://buouui.com/)  |
| KokonutUI      | Lots of effects and nicely animated components, very reminiscent of Apple's new Glassy components. | [link](https://kokonutui.com/)  |
| Junwen-k/ui-x      | A nice set of primitive components.        | [link](https://ui-x.junwen-k.dev/)  |
| SkiperUI | Beautiful but niche set of components.        | [link](https://skiper-ui.com/)  |
| AceternityUI | Lots of effects and nicely animated components. Especially great for effects, cards and text animations. | [link](https://ui.aceternity.com/) |
| LukachoUI      | Pretty small set of cool components, especially great for custom cursors. (The frontpage has a nice grid-based/minimalist design).| [link](https://ui.lukacho.com/)|
| 8BitCN| A great "retro" looking set of components.| [link](https://www.8bitcn.com/)|
| React Bits| A set of highly animated and modern components. Super great for text animations and backgrounds.| [link](https://reactbits.dev/)|
| AnimateUI| A nice set of clean primitives.| [link](https://animate-ui.com/)|
| AssistantUI| Great for complex LLM chatbots.| [link](https://www.assistant-ui.com/)|
| ShadCN Editor| A rich text editor component.| [link](https://shadcn-editor.vercel.app/)|

### Backends and DBs

| Library     | Description | Links          |
| :---        |    :----   |          :---: |
| Convex      | A relatively new backend platform with a lot of developer support. | [link](https://www.convex.dev/)  |

| Prisma ORM      | More mature than Drizzle. A little annoying to set up with NoSQL databases. | [link](https://www.prisma.io/)  |
